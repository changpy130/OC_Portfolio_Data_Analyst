Analyse public health data to identify trends and key factors affecting the population.

**🛠 Skills Applied:**  
- Data cleaning and preparation  
- Descriptive and exploratory statistical analysis  
- Creating interpretable visualisations and charts

Python (Pandas, Matplotlib, Seaborn), Jupyter Notebook

### P5 – Create and Use a Real Estate Database with SQL <a name="p5"></a>

**🎯 Objective:**  
Build a database to manage real estate information and perform analyses usable by an agency or property manager.

**🛠 Skills Applied:**  
- Database modeling and relational database creation  
- Writing complex SQL queries  
- Data analysis to extract market trends  
- Structuring and managing data for future use  

**💻 Tools Used:**  
SQL, DBeaver, UML, Draw.io  

**📈 Key Insight / Impact:**  
Enabled precise tracking of properties and transactions, identified the most profitable market segments, and improved business decision-making.

### P6 – Optimise Store Data Management with R or Python <a name="p6"></a>

**🎯 Objective:**  
Optimise the management and analysis of store data to better understand sales, inventory, and product profitability.

**🛠 Skills Applied:**  
- Cleaning and structuring sales and inventory data  
- Exploratory analysis and key metric visualisation  
- Detecting high-value or underperforming products  
- Preparing actionable recommendations for operational management  

**💻 Tools Used:**  
Python (NumPy, Pandas, Plotly, Streamlit), Jupyter Notebook  

**📈 Key Insight / Impact:**  
Highlighted products that concentrate most of the stock value and improved recommendations for prioritising business decisions and optimising sales.

---

### P7 – Create an Interactive Business Dashboard with Power BI <a name="p7"></a>

**🎯 Objective:**  
Design an interactive Power BI dashboard for Sanitoral, an international oral care company, to help executives monitor project portfolio performance across 4 global regions.

**🛠 Skills Applied:**
- Designing a Product Strategy Canvas and user stories
- Data cleaning and transformation with Power Query Editor
- Data modeling and relationship management
- DAX measures and KPI calculations (cost, deadlines, deliverables)
- Building interactive, multi-audience dashboards
- Data storytelling and visual communication

**💻 Tools Used:**  
Power BI (Power Query, DAX), UML, Draw.io

**📈 Key Insight / Impact:**  
Built a multi-page dashboard enabling three director levels (General, Regional, Country) to monitor project KPIs in real time, with automated alerts triggered when actuals deviate more than 15% from forecasts — supporting faster, data-driven decisions across IT and Marketing project portfolios.
